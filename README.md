# Internship Full-Stack Project

A full-stack internship project with separate frontend and backend applications. The repository is organized as a client-server web application and is based on the original internship project fork.

## Project Structure

- `FRONT_END/` contains the client application.
- `BACK_END/` contains the server application.

## Run Locally

Install dependencies inside each application directory, then start the backend and frontend in separate terminals according to their package scripts.
